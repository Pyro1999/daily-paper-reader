## 摘要
脑电图（EEG）是一种测量神经活动的非侵入性技术，已广泛应用于神经科学应用。近年来，EEG基础模型的进展使得在多样的神经解码任务上展现出强大性能。然而，没有一个单一的基础模型能在不同数据集或单个EEG实例上始终表现最佳，而实例级模型选择在很大程度上尚未被探索。为解决这一局限，我们将EEG基础模型选择形式化为实例级算法选择（AS）问题。我们提出\textbf{EEG-AS}，一种实例级算法选择框架，利用推理可用的潜在EEG嵌入、手工设计的神经生理学特征和一个锚定基础模型来表征每个EEG实例。在训练阶段，EEG-AS学习基于锚定基础模型，从特权预测标记中重构不可用的基础模型行为；在推理阶段，则无需执行整个模型组合即可估计这些行为，从而实现对七个EEG基础模型的高效选择。在七个公开EEG基准上的实验表明，EEG-AS显著缩小了每个实例中单一最佳求解器（SBS）与预言机上界之间的差距。这些结果凸显了实例级AS在EEG基础模型自适应部署中的有效性。

## Abstract
Electroencephalography (EEG) is a non-invasive technique for measuring neural activity and has been widely used in neuroscience applications. Recent advances in EEG foundation models have enabled strong performance across diverse neural decoding tasks. However, no single foundation model consistently performs best across datasets or individual EEG instances, while instance-level model selection remains largely unexplored. To address this limitation, we formulate EEG foundation model selection as an instance-level Algorithm Selection (AS) problem. We propose \textbf{EEG-AS}, an instance-level algorithm selection framework that characterizes each EEG instance using inference-available latent EEG embeddings, handcrafted neurophysiological features, and an anchor foundation model. During training, EEG-AS learns to reconstruct unavailable foundation-model behaviors from privileged prediction tokens conditioned on an anchor foundation model, while during inference it estimates these behaviors without executing the entire model portfolio, enabling efficient selection from seven EEG foundation models. Experiments on seven public EEG benchmarks demonstrate that EEG-AS substantially narrows the gap between the Single Best Solver (SBS) and the oracle upper bound for each instance. These results highlight the effectiveness of instance-level AS for adaptive deployment of EEG foundation models.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：脑电图（EEG）基础模型（Foundation Models, FMs）在神经解码等任务上表现优异，但已有模型数量迅速增长，研究关注点正从“训练更强的单个模型”转向“如何高效利用现有模型组合”。
- **核心问题**：没有任何单一EEG基础模型能够在所有数据集、甚至同一数据集内的所有个体实例上始终表现最佳。实际推理通常发生在单个 trial / window / recording 级别，不同FM会正确分类不同的实例，存在显著的“实例级互补性”。
- **现有实践的不足**：当前普遍做法是根据数据集平均性能选择一个最优FM（即 Single Best Solver, SBS），这隐含了“同一数据集内一个模型对所有实例都最优”的错误假设。实验表明该假设不成立，SBS与Oracle（Virtual Best Solver，每个实例选最优模型）之间存在较大性能差距，说明实例级自适应选择有巨大潜力，但相关研究尚未充分开展。
- **整体含义**：本文将EEG基础模型的部署问题形式化为实例级算法选择（Algorithm Selection, AS）问题，旨在针对每个EEG实例自动挑选最合适的FM，从而逼近Oracle上限，实现自适应、高效的模型部署。

## 2. 论文提出的方法论

- **核心思想**：利用“推理时可获得的信息”来估计“未执行的基础模型的行为”，从而避免在推理时执行整个FM组合。关键洞察是：可以用一个轻量级、推理可用的锚定基础模型（anchor FM）的预测行为，结合该实例的EEG表示，条件式地重构其他候选FM的预测输出。
- **问题形式化**：
  - 给定FM组合 M = {m1,...,mK} 和EEG实例 xi，每个FM mk 在 xi 上的效用为 ρ(mk, xi)。
  - Oracle（VBS）为每个实例选择最优FM：m*(xi)=argmax ρ(mk, xi)。
  - 目标是学习选择器 fθ，使其对每个FM输出相关分数 s(xi,mk)，并选择得分最高的FM。
- **三个核心组件**：
  1. **EEG表示模块**：提取实例的推理可用表示 zx，由冻结的BIOT编码器嵌入 ex 和手工设计的EEG特征 hx 拼接而成：zx=[ex; hx]。
  2. **条件式标记预测器**（Conditional Token Predictor）：
     - 每个FM对实例输出一个预测 token（类别概率向量 tk ∈ R^C），所有FM的token组成特权矩阵 T∈R^{K×C}，仅在训练时可用。
     - 推理时只观察锚定模型token ta，预测器 Pψ(zx, ta) 重构所有非锚定FM的token。
     - 重构后的token矩阵 ˜T 由真实锚定token和预测token组合而成：˜tk = ta（若k=a），否则为ˆtk。
  3. **基于token的模型选择器**：
     - 利用交叉注意力机制建模EEG特征与FM行为之间的交互，每个FM槽位结合EEG表示与其token构造查询，输出各FM的相关分数 s=fθ(zx,˜T)。
- **训练目标（联合优化）**：
  - **Token重构损失**：Ltoken = (1/(K−1)) Σ_{k≠a} ||ˆtk - tk||²₂，用于让预测器逼近真实FM预测分布。
  - **选择损失**：用成对排序逻辑损失（pairwise logistic ranking loss）优化选择器，仅对“相关 vs 不相关”模型构建排序约束。相关定义为该FM预测正确（argmax tk = y）。
  - 总损失 L = Lselect + λ·Ltoken（λ=1.0）。
- **推理流程**：输入实例 → 提取EEG表示 → 执行锚定FM得到其token → 预测器重构其他FM的token → 选择器给出分数并选出最优FM → 若所选FM不是锚定模型再执行之完成预测。

- **主结果**：EEG-AS在全部7个数据集上一致优于SBS，将平均选择准确率从53.7%提升至66.9%，约弥合了SBS到Oracle性能差距的44%（Oracle平均83.7%），在5/7数据集上取得最佳可部署性能。
- **对比SBS的验证**：实例级算法选择确实优于单一全局最优模型，验证了EEG-FM间存在实例级互补性。
- **组件有效性**：
  - 手工EEG特征和FM嵌入互补，两者结合最佳；
  - 锚定token提供实例级上下文，优于无锚定或全局token；
  - token级重构监督优于二元正确性监督，因为保留了预测分布细节；
  - 锚定FM选择对性能影响不大，BIOT作为默认锚是合理且鲁棒的选择。
- **重构质量**：平均余弦相似度0.66、秩相关0.67、Top-1一致率0.53，说明方法能学到有意义的FM行为，而非随意表示。
- **性能差距归因**：三个限制因素——选择余量有限（如THINGS-EEG-2上SBS已接近Oracle）、重构精度不足并非唯一瓶颈、FM间预测多样性不足导致选择信息有限。SEED-VII上即使Privileged Teacher使用完全真实token仅达43.5%，远低于Oracle 76.1%，说明“行为重构”与“最优决策对齐”是不同层面的问题。

## 7. 优点

- **问题新颖**：首次将EEG基础模型部署提升到实例级AS，突破了传统“数据集级单一模型选择”的范式。
- **方法设计巧妙**：
  - 用“预测token”而非标量分数表征FM行为，保留完整分布信息；
  - 训练时利用特权信息，推理时仅需单个轻量锚定模型，避免执行完整组合，实现了精度与效率的折衷；
  - 条件式重构依赖于实例级锚定token，能够捕捉样本特定的FM间关系。
- **框架通用性强**：EEG表示部分可以是任意推理可得的嵌入，不限于BIOT，对锚定FM选择也具有鲁棒性。
- **实验扎实**：七个跨任务数据集，多次消融和鲁棒性分析，对比体系完整（从SBS到Oracle），并深入分析了性能差距来源。
