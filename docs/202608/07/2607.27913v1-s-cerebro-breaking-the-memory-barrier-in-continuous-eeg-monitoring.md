## 摘要
基础模型为脑电图（EEG）分析提供了一种有前景的范式，利用来自海量无标注数据集的泛化表示。然而，基于Transformer的架构面临一个关键瓶颈：全局注意力机制将注意力记忆状态与信号持续时间耦合，导致连续监测期间内存溢出。为了解决这个问题，我们提出了S-CEReBrO（流式CEReBrO），这是专为连续监测设计的CEReBrO架构的演进。我们新颖的窗口化交替注意力机制将注意力计算分解为固定大小的时空窗口，由于只有活动窗口需要驻留注意力图，从而保证了恒定的KV缓存内存。经验性缩放分析证实，窗口化交替注意力可以处理的信号长度分别是全自注意力的100倍和低秩线性注意力的3倍。与长上下文上的低秩线性注意力相比，窗口化交替注意力仅需55%的内存，同时将推理吞吐量提高了2.1倍。S-CEReBrO在超过12,000名受试者的25,000多小时记录上进行了预训练，在11个下游任务中的7个上达到了最先进性能，参数减少了高达60%。这项工作朝着实现高效、可泛化的连续脑电监测迈出了重要一步。随附的代码库已可用。

## Abstract
Foundation models offer a promising paradigm for Electroencephalography (EEG) analysis, leveraging generalizable representations from vast unlabeled datasets. Yet, Transformer-based architectures face a critical bottleneck: global attention mechanisms couple the attention memory state to the signal duration, causing memory overflow during continuous monitoring. To address this, we introduce S-CEReBrO (Streaming CEReBrO), an evolution of the CEReBrO architecture designed for continuous monitoring. Our novel Windowed Alternating Attention mechanism factorizes attention computation into fixed-size spatiotemporal windows, guaranteeing constant KV cache memory as only the active window requires resident attention maps. Empirical scaling analysis confirms that windowed alternating attention can process signals 100X longer than full self-attention and 3X longer than low-rank linear attention. Compared to low-rank linear attention on long contexts, windowed alternating attention requires 55% of the memory while increasing inference throughput by 2.1X. Pre-trained on >25,000 hours of recordings from >12,000 subjects, S-CEReBrO achieves state-of-the-art performance on 7 of 11 downstream tasks, with up to 60% fewer parameters. This work represents a significant step toward the realization of efficient, generalizable, and continuous EEG monitoring. An accompanying code repository is available.

## S-CEReBrO：突破连续脑电监测中的内存瓶颈——论文总结

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心背景**：脑电图（EEG）记录大脑电活动，正在从短时临床检测走向长时间连续监测（如癫痫持续监测）。数据形态为 C 通道 × T 时间步，通道数受限（通常 2–64），而 T 随监测时长无限增长。
- **根本矛盾**：主流 EEG 基础模型（如 LaBraM、CBraMod、CEReBrO 等）均基于 Transformer 的全局（或跨通道）注意力机制。此类机制的 KV 缓存内存与信号时长 T 成正比，在连续长时监测场景下会发生内存溢出（内存崩溃），无法在可穿戴/边缘设备上部署。
- **现有应对的不足**：当前最先进模型普遍采用任意固定窗口分段（chunking）来缓解内存压力，但这种方式把 EEG 切成相互孤立、无状态的片段，破坏了连续监测所依赖的长期时间依赖关系。
- **论文意义**：提出 S-CEReBrO（Streaming CEReBrO），首次实现**严格线性注意力复杂度 + 与信号时长无关的恒定 KV 缓存内存**，在保证长程上下文连续性的同时突破内存瓶颈，向高效、可泛化、可持续运行的 EEG 连续监测迈出关键一步。

### 2. 论文提出的方法论

**核心思想**：在 CEReBrO 交替注意力架构的基础上引入**算法局部性**——通过设计固定大小的时空注意力窗口，并在计算后将过期 token 从计算缓冲区中驱逐（evict），使得驻留内存与信号长度 T 解耦。跨窗口的信息交互通过层间通道混合（WSA）逐步传递，以深度换取广度，在局部窗口内近似全局建模。

**完整流程**：

1. **时空分块（Tokenization）**：
   - 对每个通道使用长度为 L、步长为 S 的滑窗切成 patch，得到 P ∈ R^(C×Np×L)（Np 为 patch 数）；
   - 共享卷积编码器将每个 patch 映射为潜在嵌入 E ∈ R^d_e；
   - 加入可学习时间位置嵌入 W_pos 和基于 3D 电极坐标（x,y,z）经 MLP 得到的空间嵌入 W_chan，三者相加形成 Transformer 输入 H⁰。

2. **窗口化时间注意力（WTA）**：
   - 在时间维度上对每个通道独立建模，查询 q 仅与局部邻域 N_t 内的键值对计算注意力；
   - 邻域定义为 N_t(i,l) = {k | k = i + (j·d_l + s_l)}，即每个层使用不同的膨胀因子 d_l 和偏移因子 s_l 来错开感受野，在不增加内存的前提下扩大有效上下文范围；
   - 注意力公式保持标准 softmax(QK^T/√d_e)V 形式，但键值对数量由固定窗口大小 w_t 限制。

3. **窗口化空间注意力（WSA）**：
   - 在固定时间索引上促进跨通道信息交换，查询仅与 w_s 大小的通道邻域 N_s(c,l) 计算注意力；
   - 邻域定义同理为 N_s(c,l) = {n | n = c + (m·d_l + s_l)}；
   - 通过层间膨胀与偏移，让生理上相距较远但功能相关的通道能在模型深层间接交互，近似全局空间关系。

4. **关键超参数**：空间窗口 w_s = min(C,7)，时间窗口 w_t = min(T,5)，膨胀因子 {1,2,4}，偏移因子 {0,1,−1,2,−2}，注意力块对数 N=3，嵌入维度 d_e=180，注意力头数 h=5（总参数量仅 2.4M）。

5. **计算复杂度与内存特性**：
   - 标准交替注意力：复杂度 O(CT(C+T))，KV 缓存 O(T)；
   - S-CEReBrO：复杂度 O(CNp(w_t+w_s)) ∝ O(CT)，KV 缓存因驱逐过期 token 而保持 O(1) 恒定；
   - 采用 **FIFO 流式处理**代替固定窗口分块，维持有状态的连续感受野，保留长期时间依赖。

6. **预训练**：使用掩码自编码（MAE），随机遮蔽固定比例的 patch，最小化被遮蔽位置与可见位置的重构损失加权和（L = L_m + αL_v，重建损失为 MSE）。

### 6. 论文的主要结论与发现

- **内存与效率突破**：窗口化交替注意力是唯一实现严格线性注意力复杂度和恒定 KV 缓存的 EEG 基础模型架构；在 T=15,000 秒（4 小时）时，内存仅为线性注意力的 55%，推理吞吐量提高 2.1 倍；可持续处理 50,000 秒（14 小时）信号——比全自注意力长 100 倍、比交替注意力长 10 倍、比线性注意力长 3 倍。
- **性能全面领先**：在 11 个下游任务中的 7 个上达到最先进水平（包括 CHB-MIT、Neonate、PhysioNet-MI、SHU-MI、SEED-V、STEW、SEED-VIG），且仅用 2.4M 参数（比其他基础模型少 40%–60%）。
- **局部注意力并非性能瓶颈**：全局注意力在 EEG 分析中经常是冗余的；局部归纳偏置（时间窗口中相邻 patch、空间窗口中相邻通道）反而带来性能提升，尤其在持续监测典型应用场景（癫痫检测、脑力负荷、警觉度估计）中优势明显。
- **S-CEReBrO 在认知监测上的竞争力**：在 STEW 和 SEED-VIG 上不仅超过所有监督基线和全局基础模型，甚至超过同参数量的全局版本 CEReBrO，说明局部窗口注意力在这些连续监测场景中比全局建模更有效。

### 7. 优点

- **方法创新性强**：首次将 LLM 中的窗口注意力思想系统性地迁移到 EEG 领域，并针对神经信号而非文本做了专门设计（2D 时空非平行结构、层间膨胀/偏移、跨通道桥接替代全局 token 交互）。
- **理论性质清晰且可验证**：注意力复杂度与 KV 缓存内存具有明确的理论保证（O(CT) 与 O(1)），并通过缩放实验进行了实证确认。
- **效率与性能双赢**：不需要复杂的稀疏注意力实现或近似技术，只靠窗口化+逐层通道桥接就同时获得更优的内存效率和更高的准确率，方案简洁有效。
- **面向真实场景**：FIFO 流式处理保持了连续、有状态的感受野，比固定分块方案保留了更完整的长期时间上下文，更契合实际连续监测中的可穿戴部署需求。
- **模型紧凑部署友好**：2.4M 参数在资源受限的边缘设备上有较大实际应用潜力。

### 8. 不足与局限

- **缺少消融实验**：未独立验证时间窗口大小、空间窗口大小、膨胀/偏移因子各自对最终性能的影响，核心设计选择的依据不够透明。
- **长时监测评估不够充分**：内存/吞吐量优势只在合成缩放测试中展示，尚未见在真实小时级连续 EEG 数据上的端到端评估；作者也承认未来需开发长时基准来评测小时级流式性能。
- **部分任务性能不如预期**：在 TUAB、ISRUC、Mumtaz、MentalArithmetic 等任务上未超越基线（尤其是 TUAB 等临床诊断领域，仍有较大提升空间）；S-CEReBrO 的局部归纳偏置在部分任务上可能过强，限制了全局信息的利用。
- **预训练数据质量与偏差风险**：语料聚合自多个不同数据集，覆盖不同蒙太奇与参考方式，但预训练与下游评估的领域差异、数据质量不平衡等问题可能影响泛化；对脑电测量设备/通道布局的拓扑变化鲁棒性未充分讨论。
- **具体算力信息披露不足**：未给出训练 GPU 型号、数量、训练时间等关键复现信息，影响研究的可复现性评估。
