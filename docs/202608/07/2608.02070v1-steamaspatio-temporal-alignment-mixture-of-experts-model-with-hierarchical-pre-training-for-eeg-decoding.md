## 摘要
脑机接口（BCIs）已广泛应用于运动康复、疾病诊断及其他神经工程场景。然而，传统的神经信号解码算法通常泛化能力有限且适应成本高，这激发了近期对BCI基础模型的兴趣。现有方法仍难以同时实现通用可迁移性、精确解码和高效的下游适应。我们提出了STEAM，一个分层迁移框架，在EEG基础模型中调和了通用表示学习与特定范式的专门化。该框架实例化为一个双分支时空编码器，其中共享软混合专家（SSMoE）模块对齐空间和时间分支，允许互补表示通过一组紧凑的软槽交换信息。在七个下游数据集和十四种评估设置中，STEAM在比较方法中获得了最佳平均排名，且推理成本（以FLOPs衡量）具有竞争力。在Stage-I通用初始化的基础上，分层预训练策略进一步使模型专门化到目标范式，而无需从头重新训练，从而在范式特定解码准确性上取得了一致的提升。

## Abstract
Brain-computer interfaces (BCIs) have been widely used in motor rehabilitation, disease diagnosis, and other neural engineering scenarios. However, conventional neural signal decoding algorithms often suffer from limited generalizability and high adaptation costs, motivating recent interest in BCI foundation models. Existing approaches still struggle to jointly achieve general transferability, accurate decoding, and efficient downstream adaptation. We present STEAM, a hierarchical transfer framework that reconciles general-purpose representation learning with paradigm-specific specialization in EEG foundation models. The framework is instantiated as a dual-branch spatio-temporal encoder in which a shared soft mixture-of-experts (SSMoE) module aligns the spatial and temporal branches, allowing complementary representations to exchange information through a compact set of soft slots. Across seven downstream datasets and fourteen evaluation settings, STEAM attains the best average rank among the compared methods at a competitive inference cost measured in FLOPs. Building upon the Stage-I general initialization, the hierarchical pre-training strategy further specializes the model to a target paradigm without retraining from scratch, yielding consistent gains in paradigm-specific decoding accuracy.

## 2. 方法论

### 2.1 核心思想

以"**通用 → 范式 → 任务**"的三级递进逻辑组织表征学习流程：

- **Stage-I 通用预训练**：大规模无标注 EEG 上通过掩码重建 + 跨视图对比学习获得可复用骨干。
- **Stage-II 范式特化预训练**：在同一骨干上，用目标范式的多数据集持续预训练，加入监督分类目标，不从头训练新模型。
- **下游轻量适配**：仅微调嵌入模块 + 任务头（约 5.1% 参数），冻结 Transformer 骨干。

### 2.2 双分支架构

- **空间分支**：产生通道级 token（每个通道对应一个 token），建模跨通道依赖。
- **时间分支**：产生时间片段 token，建模局部到全局的时间动态。
- 两分支独立编码至中间层，**延迟交互**以保留各分支的局部结构；在高层次通过 SSMoE 进行跨分支信息交换。

### 2.3 共享软混合专家（SSMoE）

- 将空间、时间 token 序列拼接：Z^(l) = [S̄^(l); T̄^(l)]
- 通过可学习路由矩阵 Φ^(l) 计算 token 与专家槽的亲和度，得到 dispatch 权重（按 token 归一化）与 combine 权重（按槽归一化）。
- 槽表示聚合跨分支全局信息，经专家变换后按 token 特定权重分配回各分支。
- **软路由**取代 top-k 稀疏路由，使每个 token 与多个槽交互，适应 EEG 低信噪比下的分布式模式。
- 核心优势：紧凑的瓶颈式交互接口，避免独立分支编码信息隔离，且比稀疏路由稳定性更好。

### 2.4 频率感知门控注意力

- 对 token 关联信号段计算对数频带功率作为频域描述子。
- 将注意力输出与频带描述子拼接，经两层层感知机 + GELU + sigmoid 生成逐 token 标量门。
- 门控在残差连接之前对注意力输出重新加权，在编码器每一层注入频谱先验。
- 与仅在预测头做晚期融合不同，该机制在**整个编码器内部**贯穿频率证据。

### 2.5 分层预训练目标

| 阶段 | 目标函数 | 组成 |
|------|---------|------|
| Stage-I | L_I = L_rec + αL_div + λL_con | 掩码重建 + 多样性正则 + 跨视图 InfoNCE 对比 |
| Stage-II | L_II = L_rec + αL_div + λL_con + μL_cls | Stage-I 目标 + 数据集各自分类头的监督损失 |

- **掩码重建**保留各分支局部结构信息；**对比学习**对齐同一样本的时空语义。
- Stage-II 中不同数据集具有不同标签空间时，用数据集特异分类头分别计算并聚合分类损失。

### 2.6 轻量下游适配

- 仅更新空间/时间嵌入模块 + 新初始化的任务头（约 5.1% 参数）。
- 其余编码器参数冻结，减少优化器状态存储。

## 6. 主要结论与发现

1. **STEAM 在综合平均排名上显著领先**：跨 14 个评估设置，STEAM 综合排名 1.43，10 个基础模型基线平均综合排名 10.55，相差 9.12 个排位；同时推理 FLOPs 较低（1.49 G），在性能—效率权衡上优于所有对比基础模型。
2. **Stage-II 范式特化一致有效**：STEAM-Spec 在两个 MI 数据集和 SEED 上均进一步提升 BAC（如 BNCI2014001 从 53.43→55.29，SEED 从 57.20→60.83）。
3. **层次预训练收益互补**：Stage-I 与 Stage-II 各自独立提升性能，组合后最优；Stage-I 初始化使 Stage-II 特化达到目标精度**快 2.8 倍**。
4. **SSMoE 跨分支交互不可或缺**：去除后三个数据集上性能均下降；与参数匹配的 Separate Soft-MoE 相比，共享路由空间能带来更强的跨分支协调能力。
5. **轻量适配在分类任务上接近全量微调**（多数任务差距 < 1pp，部分任务反超），但在回归任务（SEED-VIG）上仍有明显差距。
6. **预训练骨干的价值不可替代**：随机初始化冻结骨干的 PEFT 在三个数据集上均大幅退化（-5.89 至 -8.87pp），说明即使冻结参数，预训练表征仍至关重要。

## 7. 优点

### 方法设计层面
1. **双分支架构符合 EEG 神经生理**：空间分支保留通道拓扑，时间分支保留局部到全局动态，避免异构线索过早坍缩。
2. **SSMoE 软路由设计精巧**：通过紧凑软槽（8 个专家）实现跨分支信息交换，兼具参数效率与表达力；soft routing 对低信噪比 EEG 模式的分布特性更适配。
3. **频率感知门控贯穿编码器**：以频带功率这一强生理先验调制各层注意力，注入频谱归纳偏置而非仅在输出端做晚期融合。
4. **通用 → 范式两阶段预训练**：精准回应"通用性与特化性难以调和"的核心矛盾，避免了每范式单独训练基础模型的昂贵成本。
5. **轻量适配参数极少**（约 5.1%），兼具实际部署价值。

### 实验评估层面
6. **评估范围广**：涵盖 6 类任务、14 种设置，大于多数同类工作（如 LaBraM、EEGPT 的评估面）。
7. **消融系统完整**：从架构组件到预训练目标、融合机制、专家数量、数据比例，形成完整证据链。
8. **数据切分严格**：预训练与下游评估数据零重叠，避免数据泄漏。
9. **控制比较严谨**：与 Separate Soft-MoE 的参数匹配实验直接排除了"专家容量增加"这一混淆变量。

## 8. 不足与局限

1. **回归场景的轻量适配失效**（SEED-VIG）：PEFT 的 RMSE（0.2037）显著差于全量微调（0.1625），说明轻量化策略对连续值预测的适用性有限，论文未深入解释原因。
2. **Stage-II 仅覆盖两个范式**：MI 与情绪，未验证在 P300、癫痫、警戒等下游任务上的特化收益；若扩展更多范式，结论可能更完整。
3. **MIRepNet 对比不完整**：仅报告 2 个 MI 数据集，未覆盖其余 5 个数据集；BrainOmni 缺少 CHB-MIT 结果，跨方法比较的完整性受影响。
