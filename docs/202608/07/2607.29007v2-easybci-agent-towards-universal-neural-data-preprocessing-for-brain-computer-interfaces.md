## 摘要
脑机接口将神经活动转化为设备指令，但其性能依赖于仍然手动、依赖专家且可重复性差的预处理。大语言模型代理可以自动化科学编码，但现有系统缺乏神经预处理所需的模态覆盖、原始数据隔离、经验积累和领域监督。我们引入了EasyBCI，一个两阶段的LLM代理，为六种信号类型规划和执行预处理流程。计划代理将每次记录概况为仅文本的数据指纹，该指纹从不向模型暴露原始数据，并选择基于文献的操作序列。执行代理生成、运行并自我纠正代码，直到满足质量标准，同时一个质量门控的经验系统将经过验证的策略保留为可复用技能。领域专家在两个决策门处进行干预，在未检测到的错误可能使下游分析失效时保留人类判断。使用固定线性分类器对EEG的评估显示，所有五个EasyBCI骨干网络都比手动流程保留了更多的任务相关可分性。在同骨干网络比较下，EasyBCI在五种配置中的四种上，对两种标签方案均优于通用编码代理。EasyBCI扩展到另外五种模态，采样率跨越近三个数量级，产生具有记录决策来源的完整可复现流程。这些结果表明，领域特定的编排可以使可审计的预处理触手可及，即使对于缺乏专门专业知识的实验室也是如此，展示了适用于其他科学领域中AI代理的设计原则。

## Abstract
Brain-computer interfaces translate neural activity into device commands, yet their performance hinges on preprocessing that remains manual, expert-dependent and poorly reproducible. Large language model agents can automate scientific coding, but existing systems lack the modality coverage, raw-data isolation, experience accumulation and domain oversight that neural preprocessing requires. We introduce EasyBCI, a two-phase LLM agent that plans and executes preprocessing pipelines for six signal types. A Plan Agent profiles each recording into a text-only Data Fingerprint that never exposes raw data to the model and selects a literature-grounded operator sequence. An Execution Agent generates, runs and self-corrects code until quality criteria are met, while a quality-gated experience system retains validated strategies as reusable skills. A domain expert intervenes at two decision gates, retaining human judgement where undetected error can invalidate downstream analyses. Evaluation on EEG with a fixed linear classifier shows that all five EasyBCI backbones preserve more task-relevant separability than the manual pipeline. Under same-backbone comparison, EasyBCI outperforms general-purpose coding agents on both label schemes for four of five configurations. EasyBCI extends to five additional modalities spanning nearly three orders of magnitude in sampling rate, producing complete reproducible pipelines with recorded decision provenance. These results indicate that domain-specific orchestration can bring auditable preprocessing within reach of laboratories lacking dedicated expertise, illustrating design principles applicable to AI agents in other scientific domains.

# EasyBCI Agent：迈向脑机接口的通用神经数据预处理

## 1. 核心问题与整体含义（研究动机与背景）

- **核心痛点**：脑机接口（BCI）的性能高度依赖原始神经信号的预处理环节，而这一环节目前仍是**手动操作、依赖领域专家、且跨实验室可复现性差**。
- **问题根源**：预处理在每一步都存在多个合理的参数选择；六种主要神经信号模态（EEG、MEG、sEEG、ECoG、fNIRS、Spike）遵循截然不同的信号处理逻辑，**没有任何单一专家能覆盖全部范围**；且不存在可供参照的"黄金标准"流水线。
- **后果严重**：仅改变预处理流程而不改动原始数据和下游分类器，即可导致高达 42% 的 trial 级预测翻转；不同实验室对同一批数据常得出不同结论。作者将预处理称为"影响下游结论的实验变量"而非单纯的准备步骤。
- **现有工具不足**：传统工具箱（MNE-Python、EEGLAB 等）缺乏自动决策层；单模态 LLM 代理（EEGAgent、EEG-AI）仅覆盖 EEG；通用编码代理（Claude Code、Codex）参数选择未依据具体数据特征。
- **文章定位**：作者提出一个能同时满足**模态覆盖、原始数据隔离、经验积累、领域专家监督**四个要求的统一框架，填补了现有系统与多中心数据聚合、基础模型预训练、临床转化等前沿需求之间的空白。

## 2. 方法论

### 核心思想
采用**"Plan-Execute"两阶段 LLM 代理架构**，将神经信号预处理从"专家手动决策"转化为"LLM 规划 + 代码自动生成 + 质量门控 + 专家关键节点监督"的半自动化流程。其核心设计原则是**用领域知识约束 LLM 的决策空间**，而非提升 LLM 本身的生成能力。

### 两阶段架构

**（1）Plan Agent（规划代理）**
- **Stage 1 — Auto-Inspect（自动检查）**：将原始信号压缩为**仅文本的 "Data Fingerprint"（数据指纹）**，包含格式、模态、通道数、采样率、频谱特征、坏道候选、伪迹指标、事件结构等摘要统计（公式：φ(x) = s, m, C, fs, T, Ψ(x), Γ(x), ε(x), η(x)）。原始数据数组**永不进入 LLM 上下文**。
- **Stage 2 — Reasoning & Planning（推理与规划）**：结合 Data Fingerprint 与用户自然语言意图，借助**网络检索到的文献证据**（如 4–38Hz 带通用于 MI-BCI 等），输出一个带步骤解释和置信度的 Pipeline Plan（算子序列）。

**（2）Execution Agent（执行代理）**
- 对每个已批准的步骤执行 **Code → Execute → Reflect 内循环**：
  - **Code**：受 Operator Contract（算子契约）约束生成 Python 函数（不可原地修改数据、失败须抛出类型化异常、禁止未声明 I/O，由 AST 静态检查器在生成时校验）。
  - **Execute**：在子进程隔离的沙箱中运行，带内存限制（RLIMIT_AS）和墙钟超时。
  - **Reflect**：自动 QC 模块按规则检查通道方差范围、频谱合理性、事件对齐完整性等，通过则进入下一步，失败则进入错误分类与修复策略，每步最多自动重试 3 次。

### 四大架构机制

| 机制 | 功能要点 |
|---|---|
| **模态感知路由** | 六种信号类型通过统一规划器调度；Loader Registry（原生）+ Skill-based interface（可扩展 fNIRS 和厂商特定 Spike 格式）两层设计 |
| **Source Data Guard（源数据防护）** | 三层保护：抽象层（LLM 只见文本指纹）、写阻断层（受保护路径不可改写）、完整性层（执行前后校验文件大小与修改时间） |
| **质量加权技能检索** | 基于规则的维度加权匹配（硬过滤器：模态+分析目标；软轴：范式、采样率等），相似度公式 sim(o,φ; s_j) = Σ w_d · f_d(...)，再乘以质量权重 λ(s_j)（基于历史 QC 通过率 ρ，低于 40% 且使用≥5 次自动弃用）。负样本档案对相似计划施加惩罚权重 |
| **Expert-in-the-Agent-Loop** | 两个专家决策门：①计划确认门（确认/修改/中止）；②修复耗尽门（自动修复 3 次失败后暂停，专家可提供修正提示、跳过或中止） |

### 其他关键设计
- **确定性执行/可复现性**：自动注入种子前导码（锁定 Python hash seed、random 和 NumPy 全局状态）；生成代码禁止导入 EasyBCI 框架命名空间；仅依赖 5 个标准科学计算包（mne, numpy, scipy, scikit-learn, matplotlib）。
- **渐进式技能精炼与联邦**：QC 通过且满足四条件（QC 合格、目标类型合格、仓库完整、无重复覆盖）的流水线自动保存为 Proven Skill；可选的跨实验室联邦模块（Ed25519 签名验证）。
- **输出成品**：自包含 mini-repository（code/ 可独立运行、plan/ 含完整决策溯源、preprocessed_output/ 含 AI-ready 的 NWB/pkl 文件与 QC 报告）。

### Benchmark / 评估协议
- **固定分类器协议**：固定特征提取（CSP，6 对滤波器 + log-variance → 12 维特征向量）和固定分类器（Fisher LDA），使**预处理成为唯一实验变量**。LDA 因容量有限无法通过非线性拟合弥补差的预处理，其准确率衡量预处理保留的任务相关线性可分性。
- **交叉验证**：分层 5 折 × 2 个 session × 3 个随机种子，报告 6 次 CV 均值的平均值和标准差。

## 6. 主要结论与发现

- **EasyBCI 全面优于手动流水线**：全部 5 个骨干在两种标签方案上均显著超过 Manual 流水线。最佳配置（DeepSeek-V4-Pro）在二分类上达 78.25%（比 Manual 高 23 个百分点），四分类上达 46.65%（比 Manual 高 21.4 个百分点）。
- **领域专用编排优于通用编码代理**：在同骨干对比中，EasyBCI-Opus 4.8 二分类 66.85% vs Claude Code 64.00%；四分类 44.70% vs 32.50%。EasyBCI-GPT-5.5 二分类 65.35% vs Codex 63.29%；四分类 40.65% vs 35.54%。四分类任务上 5/5 骨干均超越通用代理，二分类上 4/5（GPT-4o 略低）。
- **架构贡献大于骨干模型差异**：在四分类任务上，最弱骨干（GPT-4o，36.65%）也超过两个通用代理，表明领域约束、规划机制和质量反馈对预处理质量的贡献超过模型能力本身。
- **跨模态泛化成立**：同一框架在采样率横跨近三个数量级（50Hz fNIRS 到 30kHz Neuropixel）、通道数 64–384 的六种模态上均产生 QC 通过的流水线（4–9 步），无需逐次手动配置。

## 7. 优点（亮点）

- **隐私-by-架构（Privacy by Architecture）** ：原始神经信号（含个人可识别生理特征）永不进入 LLM 上下文，隐私审查简化为检查文本指纹——这是神经数据特有的强隐私需求下极具价值的设计。
- **质量门控的经验积累**：只有通过 QC 的流水线才保存为技能，且带自动弃用机制（通过率 <40% 且使用≥5 次），直接回应了"经验积累可能导致性能退化"的已知问题；负样本档案进一步加强了检索的可靠性。
- **专家监督置于正确位置**：两个决策门（计划确认、修复耗尽）恰好设在错误传播风险最高的节点，兼顾了自主性与安全性。
- **可复现性工程化**：确定性种子、禁止框架依赖、SHA-256 源文件哈希、自包含输出仓库——生成代码可在任何装有标准科学计算包的机器上独立复现结果，不需要 EasyBCI 本身。
- **评估方法学贡献**：固定分类器协议（CSP+LDA）将预处理作为唯一实验变量的思路，为后续 BCI 预处理研究提供了可借鉴的验证范式。
- **完整决策溯源**：每个参数选择都附带信号证据、文献引用和推理说明，实现了科学推理的可审计性。
- **模块化与可扩展性**：插件式 reader + 技能描述符即可接入新模态，无需修改核心逻辑。

## 8. 不足与局限

- **预处理与下游解码未闭环**：EasyBCI 的参数选择不显式考虑下游解码器的需求，仅靠质量门控间接耦合；作者承认将下游性能纳入验收标准是未来方向。
- **多模态评估深度不足**：5 个非 EEG 模态只有信号级 QC 和定向诊断，没有量化下游分类精度，降低了跨模态结论的说服力。
- **缺少消融实验**：未单独验证 Data Fingerprint、技能检索、Source Data Guard、专家门等机制各自对最终结果的贡献，因果归因不够清晰。
- **潜在偏差风险**：EEG 主实验的数据集为实验室自采（非公开基准），无法在公开数据集上验证泛化性与可复现对比；Manual 流水线由一位博士生按文献设计且未针对数据特征调整，可能低估了 Manual 条件的上限；多模态案例中"分类目标"任务的闭环验证缺失。
- **专家门可能成为瓶颈**：虽然降低了专家负担，但在完全无人值守的大规模部署场景下，计划确认和修复耗尽两个门仍需人类介入；实际使用中若专家不可用，可能阻塞流程。
- **实时/闭环场景未覆盖**：目前是批处理架构，不满足实时 BCI 的延迟约束（作者已承认）。
- **算力与成本信息缺失**：未报告 LLM API 调用成本、时间开销、token 消耗等实用部署指标。
- **统计效力有限**：每 session 仅 40 个 trial、2 个 session、3 个种子的配置下，部分条件间差异可能未达到统计学显著（论文未报告显著性检验）。
