## 摘要
近年来，脑电（EEG）基础模型的进展证明了大规模预训练在跨受试者、记录环境和数据集实现通用神经解码方面的潜力。然而，主流预训练范式面临关键挑战：掩蔽自编码倾向于优先重建低层信号而非任务相关语义，而自回归建模则造成连续神经动态与离散词元空间之间的不匹配。为应对这些挑战，需要新策略来有效对齐连续脑电表征与自然语言语义，并使之能与大语言模型集成。为此，我们提出脑潜在预测模型（BLPM），一种将异构脑电解码任务重构为连续语义嵌入预测问题的脑电-语言基础模型。BLPM引入连续脑电潜在预测（CELP）编码器，通过潜在目标预测学习可迁移表征。在此基础上，多查询语义分解（MQSD）模块提取任务相关信息，并根据语义关系在共享潜在空间中将连续脑电表征与文本语义对齐。跨多个基准的实验表明，该模型在多种任务上具有一致的泛化性能，确立了连续潜在语义预测作为脑电-语言基础模型的有效范式。

## Abstract
Recent advances in EEG foundation models have demonstrated the potential of large-scale pretraining to enable generalizable neural decoding across subjects, recording environments, and datasets. However, dominant pretraining paradigms face key challenges: masked autoencoding tends to prioritize low-level signal reconstruction over task-relevant semantics, while autoregressive modeling creates a mismatch between continuous neural dynamics and discrete token spaces. To address these challenges, new strategies are needed to effectively align continuous EEG representations with natural-language semantics and enable their integration with large language models. Accordingly, we propose Brain Latent Predictive Model (BLPM), an EEG-language foundation model that reformulates heterogeneous EEG decoding tasks as a continuous semantic embedding prediction problem. BLPM introduces a Continuous EEG Latent Predictive (CELP) encoder that learns transferable representations through latent target prediction. Building on these representations, a Multi-Query Semantic Decomposition (MQSD) module extracts task-relevant information and aligns continuous EEG representations with textual semantics within a shared latent space according to their semantic relationships. Experiments across multiple benchmarks demonstrate consistent generalization performance across diverse tasks, establishing continuous latent semantic prediction as an effective paradigm for EEG-language foundation models.

## 1. 核心问题与整体含义（研究动机与背景）

### 研究背景
- 脑电（EEG）解码研究正从任务特定模型转向基础模型，利用大规模无监督预训练学习跨受试者、记录环境和数据集的通用表征，并与大语言模型（LLM）集成。
- 当前主流 EEG 基础模型存在两类突出问题：
  - **掩码自编码（Masked Autoencoding）**：偏重重建低层信号结构，学到的表征对波形细粒度特征、噪声和个体差异敏感，且未与任务相关语义或文本语义空间显式对齐。
  - **离散词元 + 自回归建模（Tokenization + Autoregressive）**：将连续神经动态量化为有限码本会丢失判别性模式；且 LLM 天然面向离散符号，自回归下一词预测目标并不适合判别式 EEG 解码任务。

### 解决思路
- 作者提出更合理的替代范式：**在连续潜在空间中进行语义嵌入预测**，避免离散化瓶颈和生成式目标的错配，使 EEG 表征能够与语言语义对齐并支持多种异构解码任务。

## 2. 方法论

### 核心思想
- 提出 **Brain Latent Predictive Model（BLPM）**，这是一个**非生成式、非自回归**的 EEG–语言基础模型，将异构 EEG 解码任务统一重构为“从 EEG 表征预测目标答案的连续语义嵌入”的问题。
- 模型在共享潜在语义空间中工作，不需要把 EEG 转成离散神经词元，也不需要生成式词元预测。

### 关键技术细节

**（1）连续 EEG 潜在预测编码器（CELP Encoder）—— Stage 1 预训练**

| 组件 | 设计 |
|---|---|
| 输入表示 | EEG 分通道切分为非重叠段，每段视为一个 token，并采用**时域分支（1D 卷积）+ 频域分支（FFT 幅度谱线性投影）** 融合的 patch embedding，再叠加深度可分离卷积位置编码 |
| 结构化多块掩码 | 通过时间跨度掩码与通道块掩码构造可见上下文与预测目标区域 |
| 在线编码器 | 仅处理可见 token，得到潜在上下文编码 Hv |
| 目标编码器 | 处理完整 token 序列并输出潜在目标表示，采用 **EMA 动量更新**防止表征崩溃 |
| 嵌入预测器 | 从可见上下文预测被掩码位置的潜在表示 |
| 预训练损失 | 潜在空间中的 Smooth L1 损失（对比掩码重建的输入空间损失），损失在层归一化后的潜在目标上计算 |

**（2）多查询语义分解与 EEG–语言对齐（MQSD）—— Stage 2 对齐**

- 冻结 CELP 编码器，引入 **M 个语言引导语义查询**（对应时间动态、频谱特征、空间关系、形态模式等互补 EEG 因子）。
- 每个查询经过 LLM 输入嵌入层编码后，通过**交叉注意力**独立地从连续 EEG token（作为 key/value）中提取语义摘要，再经线性投影映射到 LLM 隐藏空间。

**（3）语言初始化的语义嵌入预测器**

- 将 M 个语义摘要与投影后的细粒度 EEG token 拼接，输入由 LLM 解码器层构成但**使用双向注意力掩码（非因果掩码）**的语义预测器。
- 取出查询位置的上下文隐藏状态，经平均池化和预测头，得到 L2 归一化后的预测嵌入 ze。
- 文本侧：将类别标签以自然语言形式输入预训练文本编码器得到目标语义嵌入 zy。

**（4）语义对齐目标**

- 使用**双向多正样本 InfoNCE 损失**，具有相同语义文本的样本互为正样本，防止同类误判为负样本。

**（5）多任务指令微调与语义匹配推理 —— Stage 3**

- 在 Stage 2 基础上拼接任务指令嵌入，进行非因果上下文处理，仍预测目标答案的语义嵌入。
- 推理时，对任务候选集内所有候选标签文本编码，选择与预测嵌入余弦相似度最高的标签：
  - 候选集作为输入，不用任务特定分类头
  - 全程单次前向，无自回归生成，推理开销小
- 模型使用 **LoRA（低秩适配，rank=8）** 进行参数高效微调。

## 6. 主要结论与发现

- BLPM 在 **7 个任务中的 6 个上超过所有基线**，在 PhysioNet-MI 上以 68.2% 位列第二，仅比最强基线 REVE 低 1.2%。
- 与最强基础模型基线相比的典型提升：FACED +2.3%、Mental Arithmetic +2.1%、TUEV +1.9%、COG-BCI +1.7%、TUAB +1.4%、HMC +0.6%。
- 相对最强任务特定模型提升显著：Mental Arithmetic +14.0%、TUEV +10.6%、PhysioNet-MI +9.9%。
- 消融结果表明：用潜在预测替代掩码重建、加入 EEG–语言语义对齐、采用语义引导 MQSD、用连续嵌入预测替代词元生成，四项设计均带来一致且稳定的性能提升。
- 结论：**连续潜在语义预测是构建 EEG–语言基础模型、统一异构脑电解码任务的有效范式**。

## 7. 优点

- **范式创新**：避开离散神经词元化和自回归生成两个主流但对 EEG 不一定合适的路径，在连续语义空间统一建模，表述新颖且合理。
- **架构设计细致**：
  - CELP 结合 JEPA 思想，EMA 目标编码器 + 潜在空间 Smooth L1，兼顾表征稳定性和高层语义抽象；
  - 双分支 patch embedding 同时利用时域与频域信息；
  - MQSD 用多条语言查询分解 EEG 信息，保留“同一段 EEG 可按任务取不同语义因子”的灵活性。
- **优雅的推理机制**：单次前向 + 候选集语义匹配，无自回归解码，推理开销低；候选集作为输入参量，天然适配不同任务。
- **评测规范**：标准化 NeuralBench 基准、多指标报告、5 次重复实验、异构任务覆盖广，结果可信度较高。

## 8. 不足与局限

- **性能并非全面领先**：在 PhysioNet-MI 上落后于 REVE（68.2% vs 69.4%），说明在处理细粒度运动想象判别时仍有改进空间。
- **绝对准确率偏低**：FACED（9 类情绪）的 B-Acc 仅 34.3%、TUEV 仅 57.2%，说明模型在极细粒度或类别语义高度重叠的任务上仍有明显上限。
- **算力成本与可复现性说明不足**：未报告训练总时长或 GPU 小时数；4×RTX 3090 + 1B 参数 LLM 的成本对普通实验室并不低，且完整三阶段训练流程复现门槛较高。
- **文本语义目标依赖固定嵌入模型**：标签语义由预训练文本编码器（EmbeddingGemma）固定给出，所选语义空间是否与 EEG 模态最优匹配未做深入讨论。
- **对比公平性的潜在偏差**：BLPM 采用 Llama 3.2-1B 作为 backbone，而此前工作多采用 GPT-2/Qwen 或更小的骨干；模型容量差异可能对结果产生影响，论文对此讨论有限。
- **未见跨语种、跨文化情绪标签或临床异构样本的可迁移验证**，实际临床部署时面对的真实噪声与数据偏移可能更复杂。
