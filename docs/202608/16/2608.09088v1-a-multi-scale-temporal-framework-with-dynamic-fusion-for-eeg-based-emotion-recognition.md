## 摘要
混合情绪是自动情绪识别中一个具有临床相关性但仍未充分探索的目标。脑电图（EEG）能够以毫秒级的时间分辨率访问神经活动，然而大多数EEG处理流程通过单一时间窗口分析信号，从而限制了模型可用的时间结构。本研究提出了一种用于基于EEG情绪识别的多尺度时间框架。将EEG波形分解为一个或多个持续时间的窗口，由共享的基于注意力的编码器处理，并通过动态融合模块整合，该模块为不同时间尺度分配样本特定的权重。该框架在受试者独立协议下进行二分类和三分类任务评估，其中三分类任务包含混合情感类别。二分类任务的最佳结果为65.22%，三分类任务为45.43%。两者均通过三尺度动态融合配置获得，并显著高于全信号基线。表现最佳的时间尺度在两个任务中有所不同。在最高分的二分类配置中，动态融合优于拼接融合，在最高分的三分类配置中略优于拼接融合，尽管这些多尺度设置比全信号基线需要更多的计算量。

## Abstract
Mixed emotions represent a clinically relevant but still underexplored target for automatic emotion recognition. EEG provides millisecond-level access to neural activity, yet most EEG pipelines analyze the signal through a single temporal window, thereby fixing the temporal structure available to the model. This study introduces a multi-scale temporal framework for EEG-based emotion recognition. The EEG waveform is decomposed into windows of one or several durations, processed by a shared attention-based encoder, and integrated through a dynamic fusion module that assigns sample-specific weights across temporal scales. The framework is evaluated under a subject-independent protocol in binary and three-class settings, with the three-class task including the mixed affective category. The best results are 65.22% for the two-class task and 45.43% for the three-class task. Both are obtained with three-scale dynamic-fusion configurations and remain substantially above the full-signal baseline. The best-performing temporal scales differ between the two tasks. Dynamic fusion outperforms concatenation in the highest-scoring two-class configuration and slightly exceeds it in the highest-scoring three-class configuration, although these multi-scale settings require substantially more computation than the full-signal baseline.

本研究聚焦于**混合情绪识别**这一兼具临床相关性但长期未获充分探索的课题。传统情绪识别研究通常将情绪划分为正/负或愉悦度等单一维度，而混合情绪描绘的是积极与消极成分**同时存在**的情感体验，无法用单一效价轴充分描述。在心理健康监测、人机交互等连续、无侵入的实时监测场景中，依赖回溯性自陈报告并不可靠，因此亟需基于生理信号的自动识别方法。

**核心问题有二：**
- 其一，混合情绪状态在计算层面的研究明显不足；

**研究立意**在于：通过将EEG波形分解为多个不同时长的窗口，并利用共享编码器提取特征、动态融合模块自适应加权，为EEG情绪识别（尤其是混合情绪）提供一种更灵活的多尺度时间建模方案。

### 2. 方法论

#### 2.1 总体框架

论文提出一个**多尺度时间框架**（Multi-Scale Temporal Framework），核心流程分为四步：信号裁剪 → 多尺度时间窗口化 → 共享注意力编码 → 动态融合分类。

#### 2.2 信号表示

- 每个EEG样本是一个多通道波形张量 **X ∈ R^(C×L₀)**，C为通道数（本研究为18），L₀为原始信号长度，采样率300 Hz。
- 所有信号统一裁剪至固定目标长度 L = 20秒（即6000个采样点），以消除不同时长（该数据集中含20秒与30秒两种记录）作为预测线索的偏差。
- **训练阶段**：裁剪位置在有效范围内均匀随机采样，产生多个时间视图以增强多样性；**验证/测试阶段**固定裁剪前20秒。

#### 2.3 多尺度时间窗口化

- 定义窗口时长集合 **W = {full, 2, 5, 10} 秒**，其中full表示整个20秒信号作为一个窗口。
- 每种时长wₖ产生 nₖ = ⌊L/ℓₖ⌋ 个不重叠窗口（ℓₖ为对应窗口的采样点数），窗口总数为 N = Σnₖ。
- 例如{full, 2, 10}配置产生13个窗口：1个全信号（18×6000）、2个10秒窗口（18×3000）、10个2秒窗口（18×600）。

#### 2.4 共享注意力编码器

- 所有窗口（无论时长）经过**同一个编码器**，使参数数量与窗口数N无关，仅融合头与层归一化层随配置变化。
- **Token化**：每个时间步作为一个token，包含C个通道值，并拼接13维傅里叶位置编码（M=6频带，fmax=10），形成token矩阵 T ∈ R^(ℓₖ×C′)，C′=C+13。
- **分段**：token序列划分为S=100个连续段，每段长度因窗口时长而异（2秒窗口每段6个token=20 ms；5秒每段15个=50 ms；10秒每段30个=100 ms；全信号每段60个=200 ms）。
- **层次结构**：共D=6层，潜在维度逐层压缩为{128,128,96,96,64,32}，注意力头数对应{8,8,6,6,4,2}，每层后接Rℓ个自注意力块（{8,8,4,4,2,1}）。
- **非对称交叉注意力**：每个段状态（单个向量作为query）仅从其对应token子集（作为key/value）聚合信息，注意力矩阵为1×nₛ而非方阵，所有段并行处理。
- **跨段自注意力**：段状态堆叠为 U ∈ R^(S×d)，通过Rℓ层自注意力建模整窗依赖关系。
- **窗口嵌入**：最终将S个段状态取平均，得到d=32维的窗口嵌入e，所有窗口（无论时长）映射到相同的嵌入空间。

#### 2.5 动态融合

所有N个窗口嵌入汇集成矩阵 Z ∈ R^(N×d)，通过两种融合策略整合：

- **拼接融合**：将N个嵌入直接拼接后经两层MLP分类。该方式没有样本自适应加权。
- **动态融合**（核心创新）：
  - 引入可学习的查询向量 **q ∈ R^d** 和每槽位位置嵌入 **{pᵢ}**。
  - 计算每个窗口的注意力分数：**αᵢ = (eᵢ + pᵢ)ᵀq / √d**
  - 通过softmax归一化得到权重 **wᵢ**，再将加权后的嵌入拼接：
    **E = concat[w₁e₁, w₂e₂, ..., w_N e_N] ∈ R^(Nd)**
  - 权重是**样本自适应**的，模型可根据每个样本的内容动态调整各时间尺度与位置的重要性。

#### 2.6 训练设置

- 优化器：AdamW，学习率1e-4，权重衰减0.05，cosine退火，20轮warmup（从1e-6起）。
- 训练200个epoch，batch size 32，混合精度训练，固定随机种子3407，确定性cuDNN。
- 损失函数：三分类用加权交叉熵（类别权重[0.83, 1.18, 1.09]以应对类别不平衡），二分类用标准交叉熵；标签平滑0.15。
- 数据增强（均在窗口划分前对全信号操作，跨通道同步决策）：加性噪声（信噪比1–1000），时间掩蔽（掩蔽15%–30%区间）。
- 正则化：注意力与前馈子层dropout 0.20，融合头dropout 0.20。

### 3. 实验设计

#### 3.1 数据集与评估协议

- **数据集**：DMER（Mixed Emotion Recognition dataset），73名受试者（18–35岁，平均23.06岁），观看32段视频片段（8正、8负、16混合），DSI-24无线干电极系统记录21通道EEG（300 Hz），预处理后保留18通道。混合情绪类别经PANAS与效价-唤醒-支配度自评验证。
- **任务设定**：
  - **二分类**：正 vs 负（排除混合类）
  - **三分类**：正 vs 负 vs 混合
- **Subject-independent协议**：按受试者划分，无跨集合重叠。为降低受试者难度不平衡带来的性能虚高，采用分层划分：先在三分类任务上用留一被试交叉验证估计个体分类难度，按z-score分为四组，再保证每组内含各难度组别的人员。最终划分为训练48人、验证12人、测试13人。

#### 3.2 对比设置

- **全信号基线**：将完整20秒信号作为单窗口直接送入编码器，无融合模块（二分类57.41%，三分类37.24%）。
- 共评估**29种配置**：包括4种单尺度、6种双尺度、4种三尺度、1种四尺度配置，每种配置分别用拼接与动态融合两种策略（全信号基线除外）。

#### 3.3 评测指标

验证集报告balanced accuracy、宏平均precision和宏平均F1；测试集报告balanced accuracy。

### 6. 主要结论与发现

1. **最佳性能**：二分类65.22%（{full, 2, 10}动态融合），三分类45.43%（{2, 5, 10}动态融合），均显著优于全信号基线（57.41%和37.24%）。
2. **多尺度优于单尺度**：大多数窗口化配置优于全信号基线，说明较短时间分段提供了全信号表示未能完全捕捉的判别信息。
3. **任务间最佳尺度不同**：
   - 二分类峰值包含全信号+短窗（2s）+长窗（10s），表明二元效价判别同时受益于持续性与局部信息；
   - 三分类峰值排除全信号，由2/5/10秒窗口构成，混合情绪识别更依赖**局部时间模式**。
4. **动态融合 vs 拼接**：动态融合在最优二分类配置中提升2.47个百分点（65.22% vs 62.75%），三分类仅提升0.12个百分点（45.43% vs 45.31%）。在全部配置上两者整体相当，动态融合优势主要体现在**异质时间尺度组合**场景。
5. **并非尺度越多越好**：四尺度配置并不能提升性能（二分类61.82%，三分类44.45%），峰值均出现在三尺度配置，表明紧凑且互补的尺度集合即可满足需要。
6. **计算成本是明显代价**：最优配置需要全信号基线约10–12倍的计算量，精度-成本权衡是实际应用的重要考量。

### 7. 优点

- **研究选题新颖**：将混合情绪这一临床相关但未被充分探索的类别纳入计算建模，扩展了传统情绪识别的问题边界。
- **方法设计有亮点**：
  - 共享编码器使参数规模与窗口数量解耦，模型参数仅为约5M，设计紧凑；
  - 动态融合机制通过样本自适应的注意力权重实现了跨尺度信息整合，而非机械拼接；
  - 非对称交叉注意力+段状态的层次结构巧妙地在计算效率和长程依赖建模之间取得平衡。
- **实验设计严谨**：受试者独立协议+难度分层划分减少了数据泄露和难度失衡导致的虚高；统一裁剪长度消除了时长作为混淆变量的风险；随机裁剪增强提供了多个时间视图。
- **分析维度丰富**：不局限于分类准确率，还系统分析了计算成本、不同窗口配置的贡献、两种融合策略的差异，并给出精度-成本权衡图。
