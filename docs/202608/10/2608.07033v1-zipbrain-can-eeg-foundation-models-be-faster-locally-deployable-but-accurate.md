## 摘要
本研究探讨了脑电图（EEG）基础模型（EFM）能否在不牺牲准确性的前提下实现更快的速度和本地部署。EEG基础模型是一大趋势，提供了强大的通用表示。然而，它们的计算负担随输入长度呈二次方增长，阻碍了在资源受限场景中的部署，尤其是实时临床监测。EEG的低信噪比进一步表明，许多这些令牌是冗余的，并且可以以很小的准确性代价进行压缩。我们提出了ZIPBrain，一种新颖的冗余感知EEG令牌池化模块，利用这一低信噪比特性来减少令牌数量。给定一个令牌序列，ZIPBrain将令牌划分为冗余组和唯一组，然后将每个冗余令牌与其在唯一组中最相似的对应物合并。此外，ZIPBrain作为一个无需训练、即插即用的模块，可以无缝集成到标准Transformer编码器中，且计算开销可忽略不计。在多个EEG基础模型上的大量实验表明，ZIPBrain具有很强的通用性，相对于基线实现了1.3%-10.5%的平均提升，同时与原始EEG基础模型相比，将墙钟推理时间减少了32.7%（使用CUDA Graph时最高可达41.8%）。

## Abstract
This work investigates whether Electroencephalograph (EEG) foundation models (EFMs) can be made faster and locally deployable without sacrificing accuracy. EEG foundation models are a major trend, offering strong general-purpose representations. However, their computational burden grows quadratically with input length, hindering deployment on resource-constrained scenario, particularly for real-time clinical monitoring. EEG's low SNR further suggests many of these tokens are redundant and compressible with little accuracy cost. We propose ZIPBrain, a novel redundancy-aware EEG token pooling module that leverages this low-SNR characteristic to reduce token count. Given a token sequence, ZIPBrain partitions tokens into redundant and unique groups, then merges each redundant token with its most similar counterpart in the unique group. Furthermore, ZIPBrain serves as a training-free, plug-and-play module that seamlessly integrates into standard Transformer encoders with negligible computational overhead. Extensive experiments across multiple EEG foundation models show ZIPBrain's strong versatility, achieving 1.3%-10.5% average improvement over baselines, while reducing wall-clock inference time by 32.7% (up to 41.8% with CUDA Graph) compared to the original EEG foundation models.

## 1. 核心问题与整体含义

- **研究动机**：脑电（EEG）基础模型（EFM）虽然能提供强大的通用表征，但基于 Transformer 的自注意力机制计算复杂度随输入 token 数量呈二次方增长，导致长时程、高密度 EEG 记录在资源受限场景（如实时临床监测、边缘设备）中难以部署。
- **核心洞察**：EEG 信号具有低信噪比（SNR）特性，大量 token 携带的是冗余或非判别性信息，而非任务相关信号，因此存在可压缩空间。
- **研究问题**：能否通过 token 压缩让 EFM 更快、可本地部署，同时不损失甚至提升准确性？
- **整体含义**：论文提出的 **ZIPBrain** 是一种训练无关、即插即用的 token 池化模块，可在不修改 Transformer 主干的前提下显著减少 token 数量，并在多个 EFM 上实现精度保持或提升、计算量显著下降，为 EFM 在边缘设备上的实际部署提供了可行方案。

## 2. 方法论

- **核心思想**：利用 EEG 低 SNR 导致的 token 冗余，将 token 划分为“冗余组”和“唯一组”，再将冗余 token 与唯一组中最相似的 token 合并，从而降低序列长度。
- **模块位置**：插入在 Transformer 编码块的注意力模块（Attention）与前馈网络（FFN）之间，不改变模型结构，无需训练。
- **算法四步流程**：
  1. **Pivot 选择（Step 1）**：依据 token 的 ℓ2 范数降序排序，选取范数最大的前 N_p 个 token 作为 pivot（代表核心上下文信息）。
  2. **冗余 token 识别（Step 2）**：计算每个非 pivot token 与所有 pivot 的余弦相似度累加值作为冗余分数，分数最高的 r 个 token 被划入冗余集合，其余进入唯一集合。
  3. **配对匹配（Step 3）**：对每个冗余 token，在唯一集合中寻找余弦相似度最高的 token 作为合并目标，形成分组。
  4. **范数保持合并（Step 4）**：对每个分组内的 token 取平均方向，再缩放至组内最大范数，避免朴素平均导致特征幅度衰减，保留关键 EEG 信号的表示强度。
- **表示空间选择**：ZIPBrain 是表示无关的，可在后注意力表示 X̂ 或 Q、K、V 投影上执行，并通过两阶段网格搜索自动选择最优表示空间（候选包括 Q、K、V、X̂ 及其多头聚合策略，共 7 种配置 × 11 种 pivot 比例，总搜索空间约 3,773 种）。
- **计算复杂度**：整体复杂度为 O(Nd + r(N−r)d)，最坏为 O(N²d)；其中冗余评分与特征聚合为线性，二次方项仅来自目标匹配阶段，但参与匹配的 token 子集远小于全部 token，实际开销低于自注意力。

## 6. 主要结论与发现

- ZIPBrain 在几乎全部设置下优于现有 token 压缩方法，平均提升 1.3%–10.5%（相对于基线），同时将推理时间降低 **32.7%**，配合 CUDA Graph 最高降低 **41.8%**。
- 在最高压缩比（约 80%）下，ZIPBrain 能保持甚至超过未压缩模型的准确率，说明 EEG token 的冗余度很高。
- **去噪效应**：在某些任务上，压缩后的模型准确率高于原始模型（如 BIOT/TUAB 上 AUROC 从 0.8782 提升到 0.8812；LaBraM/TUEV 上 Kappa 提升 2.21%），提示 token 池化可能抑制了任务无关或噪声信号。
- **Pooling 优于 Pruning**：在困难数据集上，保留冗余信息（合并）比直接丢弃更有效，最大提升 3.04% Kappa。
- **Pivot 的重要性**：高范数的 pivot token 类似于 attention sink，保留它们（归入唯一组）有助于维持模型稳定性。
- 总体结论：token 压缩是 EFM 在资源受限、实时临床场景中部署的实用方案。

## 7. 优点

- **训练无关且即插即用**：无需重新训练或微调模型，可无缝集成到任意标准 Transformer 编码器中，计算开销可忽略。
- **针对 EEG 特性设计**：充分利用低 SNR 导致的 token 冗余，而非盲目沿用视觉领域的压缩策略。
- **范数保持合并策略**：解决了朴素平均导致特征幅度衰减的问题，保留关键 EEG 信号的表示强度。
- **表示空间模块化**：支持在 Q/K/V/X̂ 等多种表示空间上执行，并通过超参搜索适应不同模型和任务。
- **工程实用性**：计算图形状静态，可与 CUDA Graph 等加速技术兼容，适合边缘设备部署。
- **实验全面**：在多种 EFM、多种数据集、多级压缩比、多种基线上进行系统验证，并包含消融和部署 profiling。

## 8. 不足与局限

- **匹配阶段仍有二次复杂度**：虽然其子集小于全自注意力，但 O(r(N−r)d) 在最坏情况下仍可能成为瓶颈，作者也承认可探索线性复杂度近似。
- **仅覆盖推理阶段**：未结合权重剪枝、量化等互补压缩技术，未扩展到生成式 EEG 基础模型。
- **超参数搜索成本较高**：最优表示空间/聚合策略需依赖网格搜索（约 3773 种配置），且主实验基于搜索后的最优配置，可能对基线不够公平。
- **预训练 checkpoint 不可用**：所有模型均为作者自行微调，可能偏离原模型在公开基准上的表现，影响比较的客观性。
- **临床验证不足**：仅有一个边缘设备（Jetson AGX Orin）的 profiling 实验，没有真实临床实时监测场景下的端到端验证。
- **分析深度有限**：对 attention sink 现象只提供了初步热力图证据，缺乏更系统的机制分析；对“去噪效应”的解释也偏推测性。
