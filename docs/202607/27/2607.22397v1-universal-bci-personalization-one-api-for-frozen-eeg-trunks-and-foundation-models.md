## 摘要
冻结的EEG编码器日益普及，而每个模型的微调默认方式无法扩展。我们提出Nimbus Personalizer：一个统一的接口，将编码映射到贝叶斯头部再到BrainState（可选仿射中间层），该接口可置于异构的冻结主干上，无需为每种架构重新构建个性化栈。系统层面的论点是：贡献在于主干无关的API——而非作为ML新颖性的嵌入上的LDA——因此OEM厂商只需集成一次即可更换主干。证据：相同的表面在五个经典主干（EEGNet、Shallow、Deep、Conformer、ATCNet）×四个MI数据集（18个单元）以及一个基础编码器（REVE）上运行，均使用同一Personalizer。在存在嵌入容量的情况下，该头部相比于热启动微调或PEFT是一种廉价的默认中间点，其适应墙时间降低了数个数量级，同时恢复了大部分微调精度增益；仅在干净数据时进行校准的方法在12/18个单元中成立。头部的增益是证明API在存在容量时有用的支持性证据。受试者级别的置信区间识别出了最清晰的数据集，而在其他处跨越零。所有结果均为探索性（受试者级别bootstrap，无验证性检验）；何时升级适应决策逻辑在我们的配套工作（控制层）中讨论。

## Abstract
Frozen EEG encoders proliferate; per-model fine-tune defaults do not scale. We present Nimbus Personalizer: one contract encode to Bayesian head to BrainState (optional affine mid-tier) that sits on heterogeneous frozen trunks without a new personalization stack per architecture. Thesis (systems): the contribution is the trunk-agnostic API - not LDA-on-embeddings as an ML novelty - so OEMs integrate once and swap trunks. Evidence: the same surface runs on five classical trunks EEGNet, Shallow, Deep, Conformer, ATCNet x four MI datasets (18 cells) and on a foundation encoder (REVE) under the same Personalizer. Where embedding capacity exists, the head is a cheap default mid-point versus warm-start fine-tune or PEFT, costing orders of magnitude less adaptation wall time while recovering much of the fine-tune accuracy gain; calibration-only-when-clean holds in 12/18 cells. Head gains are supporting evidence that the API is useful where capacity exists. Subject-level confidence intervals identify the clearest dataset and span zero elsewhere. All results are exploratory (subject-level bootstrap, no confirmatory tests); the decision logic for when to escalate adaptation is addressed in our companion work on the control layer.

## 2. 论文提出的方法论：核心思想、关键技术细节

- **核心思想**：提供一个统一的个性化合约：`wrap(model.encode) → 可选仿射映射 → Bayesian head → BrainState`。集成商只需将冻结骨干的编码器封装成一个可调用对象，Personalizer在其输出嵌入上运行，无需修改骨干权重。
- **关键技术细节**：
  - **编码器边界**：集成商提供一个从试次到嵌入行的映射（可调用、sklearn转换器或torch模块方法）。
  - **贝叶斯头**：默认使用LDA（线性判别分析），可选QDA（二次判别分析）或Softmax头，通过`head`参数切换。头部在校准嵌入上拟合，可在线更新。
  - **三个个性化层级**（在同一API下）：
    - L0：仅校准（calibration-only），在干净校准数据上拟合贝叶斯头，无需适应标签。
    - L1：流式（stream）Personalizer，L0头加上在线更新（有标签适应试次）。
    - L2：仿射映射+头，在嵌入上学习有监督的仿射变换，然后施加相同的Personalizer头。
    - L3（逃逸舱）：完全微调，更新骨干权重（仅在需要时使用）。
  - **结构化预测**：返回`BrainState`，包含主要意图、归一化置信度、不确定性、备选方案，而非裸标签。

## 3. 实验设计：数据集、benchmark、对比方法

- **Benchmark与对比方法**：
  - 对比L0（校准仅头部）、L1（流式头部更新）、L2（仿射映射+头部）、L3（完全微调）。

- **实验协议**：
  - 每个受试者采用三会话几何：校准=第一会话，适应=中间会话，评估=最终会话。
  - 适应标签预算n=40（Shin为n=20）。
  - 预处理：带通8-30Hz，时间窗口[0.5,2.5]s，相同过滤用于所有经典骨干。
  - 骨干只在干净校准数据上训练，然后冻结。
  - 引入**合成通道混合应力**（channel-mix stress）：将适应和评估EEG通过一个随机排列和符号偏置的凸混合进行扰动，应力等级{0,0.25,0.5,0.75}。校准保持干净。

## 6. 论文的主要结论与发现

- **主要结论**：
  1. **主干无关API可行**：同一Personalizer接口可在5个经典骨干（EEGNet, Shallow, Deep, Conformer, ATCNet）和基础模型REVE上无改动运行。
  2. **廉价默认路径有效**：贝叶斯头（L1/L2）在存在嵌入容量时，相比完全微调（L3）可节省数量级的适应时间，同时恢复大部分精度增益（约65-90%）。在多个单元上甚至超过完全微调精度（如BNCI EEGNet/Shallow, Zhou EEGNet）。
  3. **校准仅在干净时可靠**：在12/18单元格中，干净条件下校准仅头部（L0）是最优选择。
  4. **严格序贯升级条件性**：要求严重时使用仿射中层（L2）的严格序贯仅5/18单元成立；cal-only-when-clean才是较可靠的默认。
  5. **头部选择依赖数据集和应力族**：LDA是安全默认，QDA仅在BNCI和通道混合应力下表现突出；跨应力族验证表明LDA更稳定。
  6. **REVE基础模型上**：Personalizer仍是比LoRA/last/full FT更廉价的中间点，但绝对精度仍低于在相同数据集上训练的经典骨干。

  - 实时性上，推理延迟在MPS上仅几毫秒，但临床BCI系统还需考虑端到端延迟（未报告）。
